# Лабораторная работа №5 — «Империя звёзд», вариант 9

## Назначение программы

Консольная пошаговая игра о развитии космической империи. Игрок управляет казной,
ресурсами, корпорациями и маршрутами между планетами и астероидами.

## Сборка и запуск

Требуется компилятор C++ с поддержкой C++17 и `make`.

```bash
make
./empire_of_stars
```

Запуск автоматических проверок: `make test`.
Удаление результатов сборки: `make clean`.

## Управление

При запуске задаются количество планет, количество астероидов и seed генератора.
Seed позволяет воспроизводить одинаковую карту. В меню доступны просмотр карты,
информация о планете, просмотр казны и склада, строительство и улучшение корпораций,
создание и улучшение маршрутов, покупка и продажа ресурсов, перемещение между планетами
и завершение хода.

Игрок сам выбирает пункт «0. Завершить ход». После этого программа автоматически
выполняет работу корпораций, начисляет добытые ресурсы и доход, рассчитывает расходы
на перевозку, обновляет номер хода и проверяет условия завершения игры.

## Основные классы

| Файл | Назначение |
|---|---|
| `Resource.h/.cpp` | Базовый ресурс и конкретные виды ресурсов |
| `CelestialBody.h/.cpp` | Общий базовый класс планет и астероидов |
| `Planet.h/.cpp` | Планета и размещённые на ней корпорации |
| `Route.h/.cpp` | Маршрут, его уровень и стоимость перевозки |
| `Galaxy.h/.cpp` | Хранение космических объектов, маршрутов и поиск пути BFS |
| `Corporation.h/.cpp` | Базовая корпорация, конкретные виды корпораций и фабрика |
| `Empire.h/.cpp` | Казна, склад и планеты игрока |
| `Game.h/.cpp` | Игровой цикл, консольное меню и правила хода |
| `main.cpp` | Ввод настроек и запуск игры |
| `tests/test_logic.cpp` | Автоматические проверки логики |

## ООП и паттерн

В проекте используются наследование и полиморфизм: `Planet` и `Asteroid` наследуются
от `CelestialBody`, а конкретные корпорации — от `Corporation`. Для создания объектов
корпораций используется Simple Factory (`CorporationFactory`). Владение динамическими
объектами организовано через `std::unique_ptr`.
